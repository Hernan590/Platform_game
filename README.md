# Platform Game

Platform Game es un sencillo videojuego web desarrollado con Phaser, en el que el objetivo es recolectar la mayor cantidad de monedas posible mientras evitas obstáculos y enemigos a lo largo del camino.

## Características

- Movimiento del personaje con animaciones.
- Enemigos con trayectorias automáticas.
- Detección de colisiones con plataformas y enemigos.
- Diseño adaptable.

## Tecnologías

- HTML5
- JavaScript
- [Phaser 3](https://phaser.io/)
- Css
